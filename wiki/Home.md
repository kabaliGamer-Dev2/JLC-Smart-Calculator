## 🌟 Overview

The **Java LLM Smart Calculator (JLC)** is a hybrid computing platform and mathematical intelligence assistant. It decouples natural language understanding (using LLMs like Groq, OpenAI, and Ollama) from mathematical computation (handled deterministically by Java with bit-for-bit accuracy).

```
[ Natural Language Query ] ──► [ LLM Intent Extractor ] ──► [ Sandboxed Java AST Engine ] ──► [ Exact Result ]
```
